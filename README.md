# oa-hours · 泛微 OA 工时统计工具

自用的工时统计小工具：登录泛微 e-cology OA，实时拉取考勤数据，按月展示每日有效工时、月平均工时，并计算当天达标所需的目标签退时间。

## 功能

- 工具内直接登录 OA（账号密码），会话过期自动重登，无需手动维护 Cookie
- 按月展示每日有效工时（签到/签退 → 工时计算）
- 月平均工时、达标天数统计
- 当天目标签退时间：根据签到时间反推达到达标工时的签退点
- 暗色主题 Web 界面（React + NextUI v2）
- 登录凭据 AES-256-GCM 加密存本机，除凭据外不落任何数据

## 工时计算规则

设签到时间 `in`、签退时间 `out`：

| 签到时间 | 计薪起点 | 扣除 | 公式 |
|---------|---------|------|------|
| in ≤ 8:30 | 8:30 | 午休 1.5h | (out − 8:30) − 1.5h |
| 8:30 < in ≤ 9:00 | in | 午休 1.5h | (out − in) − 1.5h |
| in > 9:00 | in | 午休 1.5h + 晚饭 0.5h（仅当 out > 18:00） | (out − in) − 2h |

- 达标工时 = **8.5h**
- 月平均工时 = 只对有签退数据的天求平均，周末/请假/异常不计入

## 构建与运行

```bash
# 完整构建（前端 + Go 二进制）
make build

# 运行（默认监听 0.0.0.0:8080）
./oa-hours
# 自定义参数
./oa-hours -port 9090 -oa http://office.macrosan.com -data ~/.oa-hours
```

浏览器访问 `http://<本机IP>:8080`，输入 OA 账号密码即可。

## 命令行参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `-addr` | `0.0.0.0` | 监听地址 |
| `-port` | `8080` | 监听端口 |
| `-oa` | `http://office.macrosan.com` | OA 系统地址 |
| `-data` | `~/.oa-hours` | 数据目录（存加密凭据） |

## 开发

```bash
# 后端测试（含工时计算单测）
go test ./...

# 前端开发模式（热更新，代理 /api 到 8080）
cd web && npm run dev
```
